## 목표

자동 백업을 끈 상태에서 수동 백업·보호·실행 기록을 운영 절차로 만들고, 별도 DB에 실제로 복구해 서비스 데이터 정합성을 확인한다.

## 작업 단계

1. 백업 절차 문서: 실행 시점(마이그레이션·대량 수정·개인정보 파기 전, 업무 데이터 변경일 종료), 명령, 확인 방법.
2. 실행 기록 양식: 담당자·시점·대상·결과.
3. 백업 보관 위치(운영 DB와 분리)와 접근 보호 요구를 인프라에 전달하고 회신을 기록한다.
4. 별도 DB에 복구 → 앱을 `validate` 모드로 기동 → 결제·이용권·이용 참조와 M9 집계 결과를 백업 시점과 비교하는 정합성 쿼리를 작성·실행한다.
5. 백업 보존 기간은 #99 결정 전까지 미정으로 표시한다.

## 제외 범위

- 자동 백업 활성화, 보존 기간 확정 (#99)

## 검증

- 별도 DB 실복구와 정합성 쿼리 결과 기록
