## 목표

정형 집계와 자연어 분석 결과를 화면과 같은 수치·조건으로 CSV 파일로 내보낸다.

## 작업 단계

1. CSV 생성기: 머리말(조회 조건·단위·통화·기준 시각), 인코딩, 최대 1,000행과 잘린 사실 표시.
2. 수식 주입 방지: `=`, `+`, `-`, `@`로 시작하는 값을 수식으로 실행되지 않게 처리한다.
3. M9 집계 내보내기: 원 조건으로 권한을 다시 확인하고 같은 공통 집계를 호출한다.
4. M10 자연어 결과 내보내기: #95 실행 결과를 같은 방식으로 내보낸다.
5. 감사: 요청자·조건·행 수·시각.
