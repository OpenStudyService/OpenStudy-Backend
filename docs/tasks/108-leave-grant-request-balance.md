# BE-108 휴가 부여·신청·승인·반려·취소·잔여량

- 이슈: [#108 휴가 부여·신청·승인·반려·취소·잔여량](https://github.com/OpenStudyService/OpenStudy-Backend/issues/108) · M12 · `type:feature`, `layer:controller`, `layer:service`, `layer:persistence`

- 선행: #106 (열림), #83 (완료)
- 후속: #109 (승인 휴가와 대체근무 충돌)
- 인수 조건 진행: 0 / 10 (2026-11-06 조회)

## 목표

0.5일 단위 휴가를 수동 부여하고, 승인·승인 취소 때만 사용·복원을 한 번 반영하며, 근무 충돌과 잔여량이 원장과 일치하게 한다.

## 작업 단계

1. 마이그레이션: `leave_requests` 신청 지점 칼럼 등 필요한 구조를 새 버전 SQL로 추가한다(V1 수정 금지).
2. 부여: 원부여 지점 MANAGER 이상, 0.5일 단위·적용 기간·사유 기록.
3. 신청·신청 취소: 본인의 활성 소속 지점, 0.5일 단위, 기간 달력 일수 이하, 같은 연도. 신청만으로 잔여량을 줄이지 않는다.
4. 승인: 신청 지점 MANAGER 이상. 잔여량 부족, 다른 승인 휴가와 겹침, 취소되지 않은 예정 근무와 겹침이면 겹친 대상과 함께 거부한다.
5. 배분: 만료일이 빠른 부여부터 차감하고 배분을 기록한다. 사용은 한 번만 반영한다.
6. 반려(잔여량 불변)와 승인 취소(같은 부여로 한 번만 복원, 동시 취소 안전).
7. 잔여량·사용/복원 내역 조회: 본인 또는 관리 범위 직원. 잔여량 = 부여·사용·복원 원장 합계.
8. 승인된 휴가가 M8 근무 등록 충돌 검사에 걸리도록 연결한다.

## 제외 범위

- 자동 법정 휴가 계산

## 검증

- HTTP·DB 통합 테스트: 0.5일 경계, 잔여량 부족, 근무 충돌, 배분 순서, 동시 승인·취소, 원장 합계, M8 충돌 재검증
