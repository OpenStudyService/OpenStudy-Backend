# BE-124 필터 수정·최근 질의·후속 질문·실행 계획 재사용·내보내기 API 계약

- 이슈: [#124 필터 수정·최근 질의·후속 질문·실행 계획 재사용·내보내기 API 계약](https://github.com/OpenStudyService/OpenStudy-Backend/issues/124) · M15 · `type:feature`, `layer:controller`
- 상태: **선행 대기** (M15 전체의 시작점)
- 선행: #92 M10 계약 (열림)
- 후속: #125, #126, #127
- 인수 조건 진행: 0 / 4 (2026-11-06 조회)

## 목표

M15 기능의 API를 먼저 확정해 Backend와 Frontend가 같은 계약으로 병행하게 한다.

## 작업 단계

1. #92 자연어 분석 계약과 ADR-M15-001을 확인한다.
2. M10 계약에 operation을 추가한다: 필터 수정 재실행, 최근 질의 목록·재실행, 후속 질문 문맥 표시, 계획 재사용 페이지·정렬·상세, CSV 내보내기.
3. 오류 응답: 권한 변경으로 재사용 불가, 계획 만료, 수정 불가 필드 등.
4. 후속 질문 응답에 이어받은 조건과 바뀐 조건을 구분하는 필드를 둔다.
5. CSV 형식: 머리말(조건·단위·통화·기준 시각), 인코딩, 최대 행.
6. 모든 재사용 경로에서 권한을 다시 확인한다는 규칙을 문서에 적고 `openapi.json`에 반영한다.

## 제외 범위

- 구현 (#125~#127)

## 검증

- 계약 문서와 `openapi.json` operation 목록 대조, 계약 테스트
