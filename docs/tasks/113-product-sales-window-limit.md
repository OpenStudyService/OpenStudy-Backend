## 목표

상품의 판매 기간과 전체 판매 한도를 설정하고, 기간 밖·한도 초과 상품의 신규 판매를 막는다.

## 작업 단계

1. `products`에 판매 시작·종료·한도 칼럼을 새 버전 마이그레이션으로 추가한다. 비어 있으면 기존처럼 판매한다.
2. 설정 API를 만들고 변경을 상품 이력에 남긴다.
3. M4 판매 흐름에 판매 가능 확인을 넣는다: 판매 중지 → 기간 외 → 한도 초과 순서, 각각 다른 사유.
4. 남은 한도 = 승인 − 환불. 실패 결제는 한도를 쓰지 않는다.
5. 동시 판매 제어: 남은 한도 1에서 동시 두 건이면 한 건만 승인.
6. 한도를 현재 판매량보다 낮게 바꾸는 경우를 계약대로 처리한다.
