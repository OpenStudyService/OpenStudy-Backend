# BE-095 검증된 QuerySpec 실행과 결과·해석 근거 반환

- 이슈: [#95 검증된 QuerySpec 실행과 결과·해석 근거 반환](https://github.com/OpenStudyService/OpenStudy-Backend/issues/95) · M10 · `type:feature`, `layer:service`, `layer:persistence`

- 선행: #94 (열림), #87 (완료)
- 후속: #96 (함께 검증), #97, #125, #127
- 인수 조건 진행: 0 / 6 (2026-11-06 조회)

## 목표

검증된 QuerySpec만 M9 공통 집계와 허용된 JPA 조회로 실행하고, 같은 결과로 데이터셋·ViewSpec·해석 근거를 돌려준다.

## 작업 단계

1. 검증된 QuerySpec → M9 공통 집계 조건 변환과 실행. 모델이 만든 SQL·JPQL 원문을 실행하는 경로를 두지 않는다.
2. 결과 크기: 페이지 50행, 상한 1,000행, 차트 상위 20개. 잘린 범위를 메타로 표시하고 페이지 요청은 같은 실행 결과 기준으로 이어간다.
3. ViewSpec 바인딩 사전 검증: 결과 필드·타입과 맞지 않으면 렌더링 전에 거부.
4. 빈 결과·0·해당 없음 구분. 빈 결과는 오류가 아니라 적용 필터와 함께 반환.
5. 해석 근거 반환: QuerySpec, 기준 시각(좌석 점유 등 시점성 데이터 포함), 필터, 지표 정의.
6. 고정 명세 기반 대표 질문 세트를 만들어 M9 정형 API 결과와 대조한다.
