# BE-090 운영 홈 요약·내 업무·연결 대상

- 이슈: [#90 운영 홈 요약·내 업무·연결 대상](https://github.com/OpenStudyService/OpenStudy-Backend/issues/90) · M9 · `type:feature`, `layer:controller`, `layer:service`
- 상태: **착수 가능**
- 선행: #86 (완료), M5·M7·M8 원본 기능 (완료)
- 후속: #104
- 인수 조건 진행: 0 / 6 (2026-11-06 조회)

## 목표

현재 이용 좌석·오늘의 업무·미처리 문의·오늘의 근무·점검 필요·공지·메시지를 원본 기능의 집계로 묶어 홈 API(`modules/home`)로 제공한다. 원본 집계 로직은 재구현하지 않고 호출한다.

## 작업 단계

1. #86 계약의 홈 요약 operation과 M9-D08·D09(업무 완료율, 이동 대상)를 확인한다.
2. 범위 처리: 선택 지점(`scope`) 또는 OWNER 전체 범위, 접근 가능한 지점만 집계.
3. 내 업무 조건: OWNER는 선택 범위 업무, 직원은 본인 업무가 기본. 조건을 바꾸면 다시 계산.
4. 카드별로 원본 서비스를 호출한다: 좌석(M5), 업무·문의·점검·공지·채팅(M7), 근무 동료(M8).
5. 오늘의 업무·완료율: 분모 0이면 "해당 없음"(`Ratio` 객체).
6. 각 항목에 이동 대상(화면 종류·대상 ID·지점)을 넣는다.
7. local 전용 `LocalPreviewController`의 `GET /api/home` 샘플과 실제 API가 겹치지 않게 정리한다.

## 제외 범위

- 원본 기능 집계 로직 재구현

## 검증

- HTTP·DB 통합 테스트: 원본 변경 후 홈 값 일치, 범위·역할별 결과, 완료율 경계, 이동 대상
