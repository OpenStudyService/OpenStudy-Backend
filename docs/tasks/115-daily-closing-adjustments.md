## 목표

지점·날짜별로 매출을 마감하고, 마감 후 변경을 사유와 함께 추적한다.

## 작업 단계

1. 마감·조정 이력 테이블을 새 버전 마이그레이션으로 추가한다.
2. 마감 실행: 해당 지점 MANAGER 이상, 같은 지점·날짜는 한 번만. M9 공통 집계로 스냅샷을 만든다.
3. 마감된 날에 영향을 주는 환불 등 변경 시 조정 이력(사유·처리자·금액)을 만든다. 환불 자체는 막지 않는다.
4. 환불 기준(처리일·원결제일)에 따라 조정이 붙는 마감일을 계약대로 정한다.
5. 마감 조회: 마감 금액·조정 합계·현재 금액, 마감 금액 + 조정 합계 = 현재 금액.

## 제외 범위

- 마감 해제

## 검증

- HTTP·DB 통합 테스트: 중복 마감, 스냅샷과 M9 집계 일치, 마감 후 환불 조정, 금액 등식
