# BE-065 타 지점 입실 고객 조회 횟수 제한

- 이슈: [#65 타 지점 입실 고객 조회 횟수 제한 (후속)](https://github.com/OpenStudyService/OpenStudy-Backend/issues/65) · M11 · `type:feature`, `layer:service`
- 상태: **결정 대기** (선행 구현은 완료, 제한값 미확정)
- 선행: #62 (완료), 제한값 사용자 결정
- 후속: 없음
- 인수 조건 진행: 0 / 4 (2026-11-06 조회)

## 목표

회원번호·연락처 정확 일치 조회가 고객 정보 대량 확인에 쓰이지 않도록 직원·지점 기준으로 횟수를 제한한다.

## 작업 단계

1. 실제 입실 조회 사용량을 근거로 제한값(횟수·시간창)을 제안하고 사용자 확정을 받는다. 임의 값을 넣지 않는다.
2. `LoginAttemptLimiter`의 고정 창 계수기를 공통 컴포넌트로 분리한다. 로그인 제한 동작은 그대로 유지한다.
3. 정확 일치 조회 진입점에 직원·지점 기준 제한을 적용하고, 초과 시 공통 429를 반환한다(조회 결과·고객 존재 여부 비노출).
4. 제한 초과를 감사 기록에 남긴다.

## 제외 범위

- 다중 인스턴스 공유 저장소, 로그인 제한값 변경

## 검증

- 계수기 단위 시험, 기존 로그인 제한 시험 회귀, HTTP 시험(429·감사)
- 정상 입실 흐름이 확정 제한값 안에서 막히지 않는지 확인
