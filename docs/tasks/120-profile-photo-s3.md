# BE-120 프로필 사진 업로드 검증과 S3 저장

## 목표

본인 프로필 사진을 서버에서 검증해 S3 비공개 버킷에 저장하고, 재방문 시 올바르게 표시한다.

## 작업 단계

1. 저장소 포트를 정의하고 S3 어댑터와 로컬 개발·테스트용 대체 구현을 만든다.
2. 업로드 API: 본인만, 파일 시그니처로 JPG·PNG·WebP 확인(확장자 위조 거부), 5MB 초과 거부.
3. 조회: 인증된 사용자만, 앱 경유 또는 짧은 만료 서명 URL.
4. 교체·삭제: 사진을 바꾸면 이전 파일은 더 이상 조회되지 않는다.
5. 인프라 요청 사항(버킷·IAM·암호화)을 전달하고 운영 확인 결과를 기록한다.

## 제외 범위

- 이미지 편집

## 검증

- 단위·통합 테스트: 형식 위조, 크기 경계, 권한, 교체 후 이전 파일 접근
- 운영 S3 확인은 인프라 회신으로 별도 기록
