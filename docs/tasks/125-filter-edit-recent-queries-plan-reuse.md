# BE-125 해석 필터 수정 재실행·최근 질의·실행 계획 재사용

- 이슈: [#125 해석 필터 수정 재실행·최근 질의·실행 계획 재사용](https://github.com/OpenStudyService/OpenStudy-Backend/issues/125) · M15 · `type:feature`, `layer:controller`, `layer:service`
- 상태: **선행 대기**
- 선행: #124, #94, #95, #96 (열림)
- 후속: 없음
- 인수 조건 진행: 0 / 6 (2026-11-06 조회)

## 목표

모델을 다시 부르지 않고 필터 수정·최근 질의 재실행·페이지·정렬·상세를 처리하되, 매번 현재 권한과 상한을 다시 확인한다.

## 작업 단계

1. 필터 수정 재실행: 기간·지점·상품만 수정 가능, 바뀐 명세를 M10 검증기(#94)로 재검증 후 실행. 모델은 호출하지 않는다.
2. 권한 밖 지점으로 수정하면 실행하지 않고 다른 지점 정보를 노출하지 않는다.
3. 최근 질의: 본인 것만 30일 안 최신 20건. 다른 사용자의 질의는 ID로 직접 요청해도 숨긴다.
4. 최근 질의 재실행: 현재 권한으로 재검증하고, 권한이 줄었으면 거부 또는 범위 축소 안내.
5. 실행 계획 재사용: 같은 세션 30분 안에서 페이지·정렬·상세에 재사용, 요청마다 권한과 1,000행 상한 확인, 권한이 바뀌면 재사용하지 않는다.
6. 같은 조건이면 재사용 결과 수치가 처음 실행과 같은지 확인한다.

## 제외 범위

- 모델 호출 경로 변경

## 검증

- 통합 테스트: 모델 호출 횟수, 권한 밖 수정, 타인 이력 접근, 권한 축소 후 재실행, 계획 만료, 권한 변경 후 재사용
