# BE-122 감사 로그 검색과 변경 전후 상세

## 목표

OWNER가 대상·행위·기간 등으로 감사 로그를 검색하고 주요 변경의 전후 값을 확인한다.

## 작업 단계

1. 검색 API(OWNER만, 그 외 403): 대상 유형·대상 ID·행위·작업자·지점·결과·기간, 페이지.
2. 허용된 조건만 받고, 기간이 없으면 기본 기간을 적용해 무제한 조회를 막는다. 필요하면 검색 조건 인덱스를 확인한다.
3. 상세 API: 전후 값·작업자·시각·요청 ID.
4. 비밀번호·토큰·민감 개인정보가 원문으로 나오지 않는지 마스킹을 확인한다.

## 제외 범위

- 감사 로그 수정·삭제 (정리는 #100)

## 검증

- HTTP·DB 통합 테스트: 권한, 조건별 검색, 기간 제한, 마스킹
