# BE-100 개인정보 익명화·감사 이벤트 정리 규칙 구조와 처리 기록

- 이슈: [#100 개인정보 익명화·감사 이벤트 정리 규칙 구조와 처리 기록](https://github.com/OpenStudyService/OpenStudy-Backend/issues/100) · M11 · `type:feature`, `layer:service`, `layer:persistence`
- 상태: **착수 가능** (규칙 구조는 지금 구현, 활성화는 #99 이후)
- 선행: #99 (열림, 활성화에만 필요)
- 후속: #104
- 인수 조건 진행: 0 / 8 (2026-11-06 조회)

## 목표

보존 기간이 정해지면 설정만 바꿔 자동 파기·정리가 동작하도록 규칙 구조와 처리 기록을 만든다. 기간 확정 전에는 모든 규칙을 비활성으로 둔다.

## 작업 단계

1. 처리 기록 테이블을 새 버전 마이그레이션으로 추가한다(V1 수정 금지, 번호는 병합 직전 main 최대값 + 1).
2. 정보 종류별 규칙 설정(기간, 활성 여부, 법정 보존 예외)을 만든다. 기간 값 없이는 활성화할 수 없게 한다.
3. 고객 식별 필드 익명화: 고객 행과 결제·이용권·이용 기록 참조를 유지한다.
4. 삭제 요청 처리와 감사 이벤트 정리(설정 기간이 지난 이벤트만)를 구현한다.
5. 정기 실행 작업을 만들고 규칙·대상 수·시각·성공/실패를 처리 기록에 남긴다. 파기한 원문은 남기지 않는다.
6. 개인정보 처리 기준 문서(수집 목적·항목·접근 권한·열람 추적·파기 기준·법정 보존 예외)를 `docs/`에 작성한다. 파기 전 수동 백업 절차(POL-03)를 포함한다.

## 제외 범위

- 기간 값 확정 (#99)

## 검증

- 통합 테스트: 비활성 기본값, 테스트 기간으로 익명화 실행 후 참조 유지와 M9 집계 결과 일치, 법정 보존 제외, 처리 기록 내용
