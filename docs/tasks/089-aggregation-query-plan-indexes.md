# BE-089 대표 집계 실행 계획 검토와 인덱스 보강

- 이슈: [#89 대표 집계 실행 계획 검토와 인덱스 보강](https://github.com/OpenStudyService/OpenStudy-Backend/issues/89) · M9 · `type:feature`, `layer:persistence`
- 상태: **선행 대기**
- 선행: #87 (완료), #88 (열림)
- 후속: #104
- 인수 조건 진행: 0 / 4 (2026-11-06 조회)

## 목표

주요 집계가 조회 조건에 맞는 인덱스를 쓰는지 확인하고, 전체 탐색이 있으면 인덱스로 줄인다.

## 작업 단계

1. Testcontainers MySQL에 대표 데이터량을 생성하는 시험 fixture를 만든다.
2. 매출(처리일·결제일 환불 기준)·지점 비교·상품 판매량·추세·최소 원장 쿼리의 `EXPLAIN ANALYZE`와 실행 시간을 측정한다.
3. 결제·환불·이용권 테이블의 전체 탐색을 찾아 필요한 인덱스만 새 버전 마이그레이션으로 추가한다(V1 수정 금지).
4. 추가 전후 실행 계획을 비교하고, 남은 전체 탐색은 이유를 기록한다.
5. 측정 결과를 `docs/`에 문서화한다.

## 제외 범위

- 집계 테이블·캐시 도입

## 검증

- 인덱스 추가 후 #87·#88 테스트 통과
- 추가 전후 `EXPLAIN ANALYZE` 비교 기록
