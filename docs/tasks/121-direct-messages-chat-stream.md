- 후속: 없음

## 목표

허용된 동료와 1:1 대화를 시작하고, 새 메시지와 업무 변경을 채팅 화면에 실시간으로 반영한다.

## 작업 단계

1. DM 대화방 생성·재사용: 활성 소속 지점을 공유하는 활성 직원과만, 같은 두 사람은 같은 대화방.
2. DM 메시지 조회·전송: M7 메시지 구조를 재사용하고 두 참여자만 접근. 소속 공유가 끊기거나 상대가 비활성화되면 전송을 막는다.
3. 채팅 전용 SSE 스트림: 공통 workspace SSE와 별도 경로. 새 메시지·업무 카드 변경 이벤트를 현재 참여자에게만 전달한다.
4. 재연결 기준(마지막 이벤트 등)을 제공해 클라이언트가 재조회할 수 있게 한다.
5. 로그아웃·권한 회수·계정 비활성 시 스트림을 닫고 이후 이벤트를 전달하지 않는다(#17 회수 처리 재사용).

## 제외 범위

- 다중 인스턴스 이벤트 전달 (#17 설계 결과를 따른다)

## 검증

- HTTP·DB·SSE 통합 테스트: 대화방 재사용, 비참여자 접근, 권한 회수 후 이벤트 차단, 재연결, 기존 workspace SSE 회귀
