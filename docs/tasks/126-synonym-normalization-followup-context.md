# BE-126 동의어·오타·띄어쓰기 정규화와 후속 질문 문맥

- 이슈: [#126 동의어·오타·띄어쓰기 정규화와 후속 질문 문맥](https://github.com/OpenStudyService/OpenStudy-Backend/issues/126) · M15 · `type:feature`, `layer:service`
- 상태: **선행 대기**
- 선행: #124, #93, #94 (열림)
- 후속: 없음
- 인수 조건 진행: 0 / 7 (2026-11-06 조회)

## 목표

표현이 달라도 같은 의미·조건이면 같은 결과를 내고, 후속 질문에서 이어받은 조건과 바뀐 조건을 구분하되 문맥으로 권한을 우회하지 못하게 한다.

## 작업 단계

1. 의미 카탈로그(#93)에 동의어를 추가한다. 추가마다 코드 리뷰와 테스트를 붙인다.
2. 오타·띄어쓰기 정규화 규칙을 만든다. 등록되지 않은 표현은 임의로 연결하지 않고 확인 또는 지원 불가로 처리한다.
3. 대표 변형 질문 세트(동의어·오타·띄어쓰기)를 만들어 원래 질문과 같은 정규화 QuerySpec·결과가 나오는지 검증한다.
4. 후속 질문 문맥: 같은 대화의 직전 성공 요청 조건을 상속하고, 사용자가 바꾼 조건은 새 값을 적용한다. 응답에 상속·변경 조건을 구분해 표시한다.
5. 선택 지점 범위가 바뀌면 문맥을 끊는다. 이어받은 지점도 현재 권한으로 재검증해 회수된 지점은 조회하지 못하게 한다.

## 제외 범위

- 관리자 동의어 편집 화면

## 검증

- 단위·통합 테스트: 변형 질문 세트, 미등록 표현, 문맥 상속·변경·끊김, 권한 회수 후 문맥 질의
