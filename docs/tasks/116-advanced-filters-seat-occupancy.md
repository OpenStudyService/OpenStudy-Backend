## 목표

결제 수단·상품 분류·처리자·상품 유형·판매/이용 지점·환불 기준으로 목록과 집계를 세분화하고, 시간 구간별 좌석 점유 추이를 원천 기록으로 재현한다.

## 작업 단계

1. M9 공통 집계 조건에 고급 필터를 추가하고, 결제 목록과 집계에 같은 필터 구조를 적용한다.
2. 응답 메타에 적용 필터를 넣는다. 매출 지표에 이용 지점 필터를 쓰면 그 의미를 메타에 표시한다.
3. 판매 지점·이용 지점 필터를 구분하고, 환불 유형 필터는 환불 기준과 처리 지점으로 동작하게 한다.
4. 좌석 점유 추이: 시간·일 구간별 값을 `seat_sessions`로 계산한다. 좌석 없는 지점은 "해당 없음".
5. 권한 밖 지점은 M9와 같은 방식으로 거부한다.
