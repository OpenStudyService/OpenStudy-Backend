# BE-093 업무 의미 카탈로그와 준비 상태

- 이슈: [#93 업무 의미 카탈로그와 준비 상태](https://github.com/OpenStudyService/OpenStudy-Backend/issues/93) · M10 · `type:feature`, `layer:service`
- 상태: **선행 대기**
- 선행: #92 (열림), #87 (완료)
- 후속: #94, #97, #126
- 인수 조건 진행: 0 / 5 (2026-11-06 조회)

## 목표

허용된 업무 의미(엔티티·필드·관계·용어·지표)를 등록하고, 지표를 실제 M9 계산과 1:1로 연결하며, 준비되지 않은 분석 실행을 막는다.

## 작업 단계

1. 카탈로그 정의: 지표(매출·판매량·발급·결제 건수·좌석 현황), 차원(기간·지점·상품·용도).
2. 민감 필드 제외 목록: 고객 이름·연락처·메모, 인증·세션 필드.
3. 각 지표를 M9 공통 집계의 지표 정의와 연결하고, 연결 누락을 검사한다.
4. 모델에 보낼 승인 메타정보 생성기: DB 원본 행을 포함하지 않는다.
5. 준비 상태 API: 하나라도 잘못되면 전체를 "준비 안 됨"과 이유로 반환하고, 그 상태에서는 질문 실행을 거부한다.

## 제외 범위

- 엔진 등록 형식 변환 (#97)

## 검증

- 단위·통합 테스트: 지표 연결 누락, 민감 필드 제외, 전송 메타정보 내용(원본 행 없음), 준비 상태 전환
