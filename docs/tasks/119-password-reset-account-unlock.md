# BE-119 본인 비밀번호 변경·관리자 초기화(이메일 링크)·계정 잠금 해제

## 목표

본인이 기존 비밀번호를 확인해 비밀번호를 바꾸고, 관리자가 원문을 다루지 않고 직원 계정을 복구할 수 있게 한다.

## 작업 단계

1. 재설정 토큰 테이블을 새 버전 마이그레이션으로 추가한다(토큰은 해시로만 저장).
2. 본인 변경: 기존 비밀번호 확인, 새 비밀번호 정책 검증. 현재 세션은 유지하고 다른 세션은 보호 API 접근을 막는다.
3. 관리자 초기화 요청: 대상 소속 지점의 `people:manage` 필요, OWNER 계정은 다른 OWNER만. 대상의 모든 세션·SSE를 종료하고 재설정 메일을 보낸다(초대 메일 worker 재사용).
4. 재설정 링크: 1시간 만료, 1회 사용, 새 링크 발급 시 이전 링크 무효.
5. 잠금 해제: 대상 계정의 로그인 제한 기록을 지운다. 다중 인스턴스 한계를 문서에 적는다.
6. 감사: 변경·초기화·잠금 해제의 처리자·대상·시각·결과. 지점 권한은 바꾸지 않는다. 응답·로그에 토큰·비밀번호를 남기지 않는다.

## 제외 범위

- 이메일 변경 (M1-08에 따라 불가)

## 검증

- HTTP·DB 통합 테스트: 기존 비밀번호 불일치, 정책 위반, 세션 종료, 권한별 초기화, 토큰 만료·재사용·재발급, 잠금 해제, 감사·로그 원문 부재
