## 목표

M1~M10 흐름을 실제 API·DB·메일·엔진에 연결해 정상·오류·권한 우회·동시 요청·재기동을 회귀 검증하고, 빈 DB와 기존 DB의 마이그레이션·초기화를 재현한다.

## 작업 단계

1. 마일스톤별 핵심 흐름과 인수 조건을 표로 정리한다(통과·실패·미검증 칸).
2. 권한 우회(scope·body 조작, 타 지점 ID 직접 요청)와 동시 요청 시나리오를 반복 실행 가능한 자동화 테스트로 만든다.
3. 재기동 후 세션·SSE·진행 상태를 확인한다.
4. 빈 DB에서 전체 마이그레이션 → OWNER 초기화 → 기동, 기존 DB 업그레이드를 문서 명령으로 재현한다.
5. #18 결과를 표에 연결하고, 실제 메일·DomainLens·운영 프록시처럼 재현하지 못한 항목은 미검증으로 분리한다.
