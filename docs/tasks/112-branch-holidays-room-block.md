## 목표

지점별 휴무일을 관리하고, 휴무일에 시작하는 스터디룸 신규 예약을 막는다.

## 작업 단계

1. 휴무일 테이블을 새 버전 마이그레이션으로 추가한다.
2. 등록·수정·삭제: 해당 지점 MANAGER 이상, 날짜 형식·중복 검증.
3. 조회: 접근 가능한 지점만. 홈 안내용 조회를 포함한다.
4. 룸 예약 검증에 휴무일 확인을 연결하고, 입력 오류와 구분되는 사유로 거부한다.
5. 휴무일 등록 시 그날 기존 예약을 경고로 반환한다(자동 취소하지 않음).
6. 판매·입실·출근·근무 등록은 휴무일에도 막지 않는다.

## 제외 범위

- 판매·입실·근무 차단

## 검증

- HTTP·DB 통합 테스트: 권한, 중복, 휴무일 예약 거부, 기존 예약 경고, 다른 업무 비차단
