## 목표

보존 기간이 없어 자동 파기·정리 규칙을 켤 수 없다. 법적 의무와 처리 목적을 근거로 정보 종류별 보존 기간을 정한다.

## 작업 단계

1. 정보 종류를 확정한다: 고객 식별 정보, 문의 내용, 근태 기록, 진단 로그 원문, 감사 이벤트, 백업 파일.
2. 종류별 수집 목적, 법정 보존 의무(법령 조항), 처리 목적 달성 시점을 조사해 표로 정리한다.
3. 법정 보존 대상과 일반 파기 대상을 구분하고 기간을 제안한다. 근거가 없는 항목은 미정으로 둔다.
4. 사용자 결정을 받아 새 ADR과 새 SRS 버전에 반영한다.

## 제외 범위

- 파기·정리 구현 (#100)

## 검증

- 결정 기록(ADR)과 SRS 갱신 확인
