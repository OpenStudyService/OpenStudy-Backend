# 로컬 워크스페이스 샘플

`local` 프로필에서 로그인 후 대시보드와 기본 목록을 둘러보기 위한 임시 조회 기능이다. 실제 로그인·CSRF·JDBC 세션을 유지하며 운영용 업무 API를 구현한 것은 아니다.

## 실행

백엔드 `.env`에 `spring.profiles.active=local`이 설정돼 있으면 별도의 샘플 옵션 없이 적용된다. 백엔드를 재시작하고 프론트엔드는 `npm run dev:live`로 실행한 뒤 로그인한다.

DB에 지점이 하나도 없는 경우에만 로컬 시작 시 샘플 지점 두 개를 만든다. 기존 지점·계정·업무 데이터는 덮어쓰지 않는다. 이 두 지점은 DB에 저장되므로 재시작해도 유지된다. 그 외 업무·좌석·문의·공지·근무·회원·상품·스터디룸은 메모리에서 응답을 구성하는 가상 데이터이며 업무 테이블에 삽입하지 않는다. 샘플 날짜는 현재 KST 날짜를 따른다.

로그인 직원의 실제 접근 가능 지점 안에서만 샘플을 만든다. 사장님은 전체 운영 지점을 볼 수 있다. 일반 직원에게 지점 소속을 자동 부여하지 않는다.

## 화면과 API

- `/api/lookups`: 프론트 공통 조회 데이터와 `preview:true` 반환. 지점·직원·좌석 등 이름 연결에 사용한다.
- `/api/home`: 오늘의 업무·좌석 이용 현황·문의·점검·공지·근무 샘플 반환.
- 업무·좌석·점검·문의·공지·직원·지점·회원·상품·스터디룸 등 기본 목록과 상세 조회 지원. 일부 후속 자원 목록은 빈 배열이다.
- 샘플 자원의 변경 요청은 `501 PREVIEW_READ_ONLY`와 안내 메시지를 반환하며 DB를 수정하지 않는다.
- 프론트 상단에 `로컬 샘플`과 조회 전용 안내를 표시한다. 샘플 모드에서는 아직 없는 업무 SSE에 연결하지 않는다.

홈·기본 목록을 확인하기 위한 범위다. 매출 분석·채팅·AI·근태의 전용 집계나 변경 기능 등은 아직 제공하지 않는다.

## 해제와 운영

`.env`에 `openstudy.local-preview.enabled=false`를 추가하면 샘플 컨트롤러와 지점 자동 준비가 비활성화된다. 로컬 샘플을 끈 뒤 실제 업무 API가 없으면 해당 화면은 다시 404가 된다. `local` 프로필이 없는 운영 환경에는 샘플 API가 등록되지 않는다. 향후 실제 업무 API를 추가할 때 이 임시 조회 컨트롤러를 제거하거나 비활성화한다.

## 검증

Docker MySQL에서 실제 로그인 후 홈·lookup·목록·상세, 지점별 분리, 익명 접근 거부, 샘플 변경 거부를 검증했다. 기존 인증 통합 테스트는 일반 프로필에 `/api/home`이 등록되지 않는 것도 확인한다. 샘플 추가 후 백엔드 전체 48개 테스트와 프론트엔드 29개 테스트가 통과했다.
