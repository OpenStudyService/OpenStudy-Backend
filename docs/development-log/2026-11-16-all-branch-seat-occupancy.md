# 2026-11-16 실시간 좌석 현황을 지점별로 비교

## 1. 배경 / 문제

- 기획서의 핵심 질문 2번은 "현재 지점별 사용 중인 좌석이 몇 개야?"다.
  - 기대 결과: 지점별 사용 중 좌석 수와 전체 좌석 수, 점유율.
- live 모드에서는 Qwen이 이 질문을 실시간 좌석 분석(POC-004)으로 바르게 분류했다.
- 하지만 POC-004는 "한 지점만 보는 분석" 목록(`SINGLE_BRANCH`, 2026-11-08 결정, ADR-M10-003)에 있었다. 그래서 여러 지점이 범위에 있으면 "어느 지점을 볼까요?"라고 되물었다.
- playback 모드에서는 "현재 … 좌석" 표현이 키워드 규칙에 걸리지 않아 지원하지 않는 질문으로 끝났다.

## 2. 검토한 선택지

- **새 등록 분석 추가**: 분석 목록, LLM 선택지 스키마, 수정 가능 조건 표, 평가 스위트까지 모두 늘려야 한다. 같은 원장, 같은 "지금 좌석" 질문을 둘로 나누게 된다.
- **POC-004가 범위에 따라 결과 형태를 고름**: 지점이 하나면 좌석 배치도, 여럿이면 지점별 비교. 분석 ID와 질문 흐름은 그대로 둔다.

## 3. 결정 및 이유

- 두 번째 방식을 선택했다.
- POC-004를 `SINGLE_BRANCH`에서 뺐다. 이로써 2026-11-08 결정 중 실시간 좌석 부분을 바꾼다.
  - 혼잡도(POC-002)는 그대로 한 지점만 보며, 지점이 여럿이면 계속 되묻는다.
- 수정 가능 조건에서도 POC-004의 지점 선택을 "한 지점"에서 "여러 지점"으로 바꿨다. 질문 흐름의 규칙과 같게 맞추기 위해서다.

## 4. 구현 내용

- `OpenStudyAnalyses`
  - 지점 한 곳의 좌석 집계를 `seatCounts`로 분리했다. 좌석 배치도 결과는 이전과 같다.
  - `executePoc004RealtimeSeats(Collection)`: 지점이 하나면 좌석 배치도, 여럿이면 지점별 비교를 반환한다.
  - 지점별 비교 결과
    - `branchSeats` 데이터셋: 지점, 운영 좌석, 이용 중, 빈자리, 차단, 점유율.
    - KPI 카드: 운영 좌석(N개 지점), 이용 중, 빈자리, 점유율(가장 높은 지점).
    - "지점별 좌석 점유율" 막대그래프와 "지점별 좌석 이용 현황" 표.
  - 키워드 규칙: "사용 중인 좌석", "이용 중인 좌석", "현재/실시간 … 좌석"도 실시간 좌석으로 읽는다.
- `AiWorkspaceService`: 조건을 바꿔 다시 실행할 때 POC-004에는 지점 범위 전체를 넘긴다.
- `AiReuse`: POC-004의 지점 조건을 여러 지점 허용으로 바꿨다.

## 5. 검증 결과

- 백엔드 AI 범위 테스트 통과: `modules.ai.*`, `domainlens.*`, `AiSalesEquivalenceIntegrationTests`.
  - 기획서 질문이 지점별 비교(막대 + 표)로 완료되는지 확인하는 통합 테스트를 추가했다.
  - 지점을 지정하면 좌석 배치도가 나오는지 확인한다.
  - 지점 선택 되묻기 테스트는 혼잡도 분석으로 옮겼다. 이때 "피크 시간대가 언제야?"를 썼다. "붐벼"는 테스트 환경에서도 생성 경로로 먼저 가서 등록 분석의 되묻기에 닿지 않기 때문이다.
- 실제 화면 확인: live 모드(Qwen) 로컬 백엔드와 프론트엔드에서 기획서 질문을 그대로 입력했다.
  - 지점을 묻지 않고 7개 지점 비교가 나왔다.
  - 운영 좌석 45석, 이용 중 33석, 빈자리 12석, 점유율 73.3%(가장 높은 곳 강남점 86.4%).
  - 막대그래프와 한국어 머리글 표가 표시됐다.
- 전체 백엔드 테스트(`./gradlew test`)는 실행하지 않았다. M11 마일스톤 테스트로 미뤘다.

## 6. 남은 작업 / 보류 사항

- 프론트엔드 PR(같은 브랜치 이름 `feature/all-branch-seat-occupancy`)과 함께 병합해야 열 이름이 한국어로 나온다.
- 지점이 여럿일 때 "지금 빈자리가 얼마나 있어?"도 이제 되묻지 않고 지점별 비교를 보여 준다. 특정 지점의 배치도는 지점 이름을 넣어 물어야 한다.
