# 2026-11-06 팀 채팅 제외·AI 채팅 단일화 범위 변경

## 1. 배경 / 문제

사용자가 화면의 팀 채팅을 보고 서비스 범위를 바꾸기로 했다. 팀 채팅 기능은 넣지 않고, 채팅 화면은 DomainLens로 자연어 DB 조회만 하는 AI 채팅 하나로 둔다. SRS v1.13에는 팀 채팅(FR-CHAT-01~09)과 업무 카드 공유(FR-TASK-07)가 남아 있었고, M7에서 채널·메시지·읽음·업무 카드(#76·#77·#155)가 구현·병합된 상태였다. M14에는 1:1 대화·채팅 스트림(#118·#121)이 열려 있었다.

팀 채팅이 남아 있던 곳:

- SRS v1.13: FR-CHAT-01~09, FR-TASK-07·08, FR-DASH-05, FR-UI-01, POL-18, 마일스톤 M7·M9·M14
- ADR-M7-001 M7-D04·D07~D09, ADR-M14-001 M14-D07·D08
- `collaboration-api.md`의 채널·메시지·업무 카드 operation 13개 + 1개, `aggregation-api.md`·`openapi.json`의 홈 메시지 카드
- `modules/chat`, V1·V3·V6의 `conversations`·`conversation_members`·`conversation_thread_reads`·`messages`, 직원 접근 축소 이벤트의 채널 참여 종료
- 열린 이슈: #90(홈 메시지), #118·#121(M14), Frontend #31·#44

## 3. 결정 및 이유

모두 사용자 선택이다. 상세는 [ADR-M10-002](../db/ADR-M10-002.md) M10-D09~D13과 SRS v1.14 POL-50·51에 있다.

- 채팅 화면은 AI 채팅 하나다. 별도 AI 분석 메뉴도 채팅 탭으로 합친다.
- 채널·메시지 구현과 테이블은 지우지 않고 설정으로 비활성화한다.
- 업무 카드 공유·채널 관리·1:1 대화·채팅 실시간은 요구사항에서 뺀다. 홈 메시지 카드는 데이터 없는 AI 채팅 바로가기로 바꾼다.
- AI 대화는 서버에 저장한다. 질문·검증된 명세·상태·기준 시각만 저장하고, 다시 열면 현재 권한으로 다시 검증·실행한다. 권한이 회수된 뒤 과거 수치가 노출되지 않도록 하려는 것이다.
- 보관 기간은 #99에서 정한다. 그전에는 사용자 삭제만 제공한다.
- 이번 작업은 문서·이슈만 바꾼다.

`openapi.json`은 이번 PR에서 바꾸지 않았다. 계약 테스트(`AggregationContractTests`·`CollaborationContractTests`)가 버전·홈 `messages` 카드·채널 operation 상태를 고정하고 있어 테스트 코드도 함께 바꿔야 하기 때문이다. 계약 문서에는 날짜를 붙인 변경 안내만 넣었다. OpenAPI와 테스트는 #90(홈 메시지 카드 제거)과 팀 채팅 비활성화 이슈에서 구현과 함께 갱신한다.

- Backend 문서만 바꿨으므로 빌드·테스트는 실행하지 않았다. `openapi.json`과 계약 테스트는 바꾸지 않았다.
- 코드의 비활성화·AI 대화 저장은 구현하지 않았다.
