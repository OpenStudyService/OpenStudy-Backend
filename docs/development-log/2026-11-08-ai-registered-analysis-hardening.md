# 2026-11-08 등록 분석 확정과 AI 데모 하드코딩 제거 (M10 #93~#96)

## 1. 배경 / 문제

- M10 #93~#96을 닫기 전에 인수 조건을 main 코드와 대조했다.
- 실제 AI는 등록된 분석 10개 중 하나를 고르는 방식이었다. 이슈가 전제한 범용 IR→QuerySpec 흐름(`QueryPipeline`·`IrValidator`·`JpaQueryExecutor`)은 연결돼 있지 않았다.
- 이식 코드에 데모 데이터에 맞춘 하드코딩이 46곳 있었다.
  - 질문 속 지점을 데모 이름("강남·성수·신규점")과 ID(9100001~3)로만 찾았다. 실제 지점 이름은 인식하지 못했다.
  - 권한 판단에 특정 직원 ID(9200003)는 매출 권한을 빼는 예외가 있었다.
  - OWNER의 "전체"를 ID 9100001 이상 지점으로 좁혔다.
  - "전 지점" 질문은 지점 수가 3개 미만이면 거절했다.
  - 좌석 분석(혼잡도·실시간 빈자리)은 지점이 비면 데모 강남점 ID로 실행했다. 확인 질문 선택지도 데모 지점을 가리켰다.
  - 품질 평가(`/api/ai/evaluation/run`)는 요청자 권한과 상관없이 데모 지점 ID로 분석을 실행했다.
  - 권한 없는 지점을 질문하면 거절 문구에 그 지점 이름을 넣었다(#94 위반).
- 기준 시각이 운영에서도 2026-11-02 14:00으로 고정돼 있었다.
  - `OpenStudyClock`에 생성자가 둘이라 Spring이 인자 없는 생성자를 골랐다. 그래서 `openstudy.ai.fixed-as-of`·`use-system-clock` 설정이 **처음부터 적용되지 않았다.**

  - 첫 지점으로 실행

## 3. 결정 및 이유

- [ADR-M10-003](../db/ADR-M10-003.md) M10-D14~D17로 기록했다.
- 지점 찾기는 실제 지점 이름으로 한다. 전체 이름, 또는 "점"으로 끝나면 그 앞부분으로 찾는다.
- 지점 범위 판단은 한 곳(`OpenStudyUserContextResolver.authorizeQuestion`)에서만 한다. 계획 단계(`OpenStudyPlaybackGateway.authorizeScope`)의 중복 구현은 이 판단을 부르도록 바꿨다. 두 구현이 데모 규칙을 각자 갖고 있어 어긋날 수 있었기 때문이다.
- 지점 선택지 `id`는 `branch:{지점 ID}:{분석 ID}`다. 서버가 받으면 범위를 그 지점으로 좁히되 권한은 다시 검사한다. 위조한 `id`로 권한 밖 지점에 닿을 수 없다.
- 품질 평가는 업무 화면이 아니라 품질 도구라서 OWNER만 실행하게 했다.

## 4. 구현 내용

- `OpenStudyUserContextResolver`
  - 데모 지점 상수, 직원 9200003 예외, 데모 지점 이름 매칭을 지웠다.
  - `mentionedBranches`는 실제 지점 이름을 쓴다(`SessionBranchService.allNames` 신규).
  - 거절 문구에서 지점 이름을 뺐다.
  - OWNER "전체"는 읽을 수 있는 모든 지점이다.
  - 직원의 "전 지점"은 모든 지점에 `ai:read`가 있을 때만 허용한다.
- `OpenStudyPlaybackGateway`
  - 범위 판단을 위임했다.
  - 데모 지점을 가리키던 확인 질문 선택지를 요청 범위 기준으로 바꿨다.
  - 실제 모델 프롬프트의 데모 지점 이름을 일반 표현으로 바꿨다.
- `OpenStudyAnalyses`
  - 한 지점 분석(`SINGLE_BRANCH`)은 지점이 정확히 하나여야 한다(`singleBranch`). 아니면 기본 지점 없이 실패한다.
  - 결과 제목·질문 문구에 실제 지점 이름을 쓴다.
- `AiWorkspaceService`
  - 한 지점 분석을 여러 지점 범위에서 물으면 `CLARIFICATION`(`BRANCH_REQUIRED`)과 지점별 선택지를 돌려준다. 질문은 확인 상태로 저장된다.
  - `branch:{id}:{analysisId}` 선택을 처리한다.
  - 품질 평가는 OWNER만 실행하고, OWNER가 읽을 수 있는 실제 지점으로 실행한다.
- `OpenStudyClock`: 인자 없는 생성자를 지웠다. `fixed-as-of`가 비어 있으면 실제 시각이다. `application.yaml` 기본값을 비웠다.
- 계약: `nl-analysis-api.md`에 지점 선택·지점 이름·기준 시각 절을 더했다. `openapi.json` 질문 operation에 `BRANCH_REQUIRED`를 더했다.
- `AiRegisteredAnalysisIntegrationTests`(신규, 4개)
  - 권한 없는 지점을 전체 이름·앞부분으로 물으면 403이고 이름이 나오지 않는다. 자기 지점은 실행된다.
  - OWNER의 "전체" 빈자리 질문은 지점 선택을 묻는다. 고른 지점만으로 실행되고 결과에 그 지점 이름이 나온다.
  - 범위가 한 지점이면 바로 실행된다.
  - 권한 밖 지점으로 위조한 선택은 403이다.
  - 품질 평가는 OWNER가 아니면 403이다.
  - 기준 시각이 현재 시각이다.
