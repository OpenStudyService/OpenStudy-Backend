# Docker 테스트 DB 정책 채택

사용자의 2026-10-19 결정에 따라 M1-12를 기존 B안(같은 서버의 전용 DB)에서 A안(Docker/MySQL 8.4 격리 DB)으로 변경했다. 자동 테스트는 Testcontainers로 수명주기와 접속 정보를 관리하고 개발 DB로 자동 대체하지 않는다. 생성한 테스트 자원만 정리하며 운영 대상 Debian 검수는 별도로 유지한다.

선택표·상세 결정·설계 안내·디렉터리 구조·개발 실행 계획 BE-005·README·DB/테스트 리소스 안내를 갱신했다. 공통 문서의 요구사항 v1.1 P23·OS-NFR-008 및 WBS의 W05·W40·BE-005도 같은 기준으로 수정했다. 이전 결정과 과거 수행 기록은 보존하고 변경 날짜를 명시했다.

변경 문구와 Git 공백 검사, 공통 문서의 서식·기존 수식/일정/공수 보존을 확인했다. 이번 작업에서 코드·의존성·테스트 프로필은 변경하지 않았다. Docker V1 SQL 검증 완료와 자동 Testcontainers 연동 구현은 구분한다. 자동 연동·Flyway/앱 통합·경합 검증은 후속이며 커밋·push는 수행하지 않았다.
