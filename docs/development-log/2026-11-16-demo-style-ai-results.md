# 2026-11-16 추천 질문 응답을 DomainLens 목업 형태로 구성

## 1. 배경 / 문제

- 추천 질문 11개의 응답이 `OpenStudy_DomainLens_v9-6_Final_Stage6.html` 목업과 달랐다.
- 목업 응답은 KPI 카드 4개, 제목·보조 문구가 있는 차트/표 패널, 한국어 열 이름으로 구성된다.
- 기존 응답은 KPI 한 개나 원시 열 이름 위주의 표였다.
- 목업과 같은 형태가 되려면 백엔드가 카드 값과 패널 구성을 ViewSpec으로 내려줘야 한다.

## 2. 검토한 선택지

- **프론트엔드에서 카드 계산**: 질문별 분기가 프론트엔드에 생기고, ViewSpec이 화면을 결정한다는 구조와 어긋난다.
- **백엔드 ViewSpec에 카드 데이터셋과 패널 추가**: 등록된 분석(POC-001~010)이 이미 ViewSpec을 만든다. 같은 자리에서 카드 데이터셋과 패널 제목·보조 문구를 정하면 된다.

## 3. 결정 및 이유

- 백엔드 방식을 선택했다.
- 카드는 `summaryCards` 데이터셋(label/value/note, 모두 문자열)으로 내려준다.
  - 금액, 비율, 요일·시각처럼 형식이 섞이므로 값은 읽을 수 있는 문자열로 미리 만든다.
- 패널 제목 앞에는 기간 단어(이번 달/지난달/이번 주/지난주)를 유지했다. 기존 기간 재제목 처리(AiPeriodTitles)와 그 테스트가 계속 동작하게 하기 위해서다.

## 4. 구현 내용

- `ResultCards` 추가
  - 카드 데이터셋과 KPI 컴포넌트를 만든다.
  - 제목·보조 문구가 있는 패널을 만든다.
  - 열 추가 도우미 `withColumns`는 출력 정의에 이미 있는 열을 중복 추가하지 않는다.
  - 표시 형식 함수(원, 건, %, 시간, 요일, 날짜 범위)를 제공한다.
- `OpenStudyAnalyses`: POC-001~010 각각에 목업과 같은 카드 4개와 패널 구성을 적용했다.
  - 매출 비교: 막대 + 지점별 집계 표.
  - 혼잡도: 히트맵 + 혼잡 시간대 TOP 5 표. TOP 5용 `peakTop5` 데이터셋을 추가했다.
  - TOP 5: 순위 막대 + 상품별 표.
  - 좌석: 좌석 배치.
  - 예약: 주간 캘린더.
  - 만료 예정: `days_left` 열이 있는 표.
  - 일별 추이: 승인액·순매출 두 선 + 일별 표.
  - 용도별 매출: `purpose_label` 열이 있는 막대 + 표.
  - 긴급 업무: 업무 목록.
  - 근무시간: `work_hours` 열이 있는 막대 + 표.
- 혼잡도 피크 셀 페이지 크기를 `max(10, 행 수)`로 바꿨다. 데이터가 모두 같은 값이면 모든 셀이 피크가 되어 페이지 크기 검증에 걸리기 때문이다.

## 5. 검증 결과

- 백엔드 AI 범위 테스트 통과: `modules.ai.*`, `domainlens.*`, `AiSalesEquivalenceIntegrationTests`.
- 전체 백엔드 테스트(`./gradlew test`)는 실행하지 않았다. M11 마일스톤 테스트로 미뤘다.
- 실제 화면 확인: 로컬 백엔드(18080)와 프론트엔드 live 모드(5185)에서 추천 질문 11개를 모두 실행했다.
  - 11개 모두 카드 4개(좌석 포함), 목업과 같은 패널 제목, 한국어 열 이름으로 표시됐다.

## 6. 남은 작업 / 보류 사항

- 프론트엔드 PR(같은 브랜치 이름)과 함께 병합해야 한다.
- 데모 모드(MSW) 응답은 아직 이전 형태다.
- 근무시간 질문은 로컬 데이터에 지난주 근무 기록이 없어 빈 차트로만 확인했다.
