# 2026-10-29 M15 최근 질의 범위·내보내기 위치·동의어 관리 정책 확정

## 1. 배경 / 문제

M15(분석 사용성·재사용 확장) 이슈를 작성하려고 SRS v1.12의 M15 요구사항 6개와 M10 결정을 확인했다. 다음이 정해지지 않았다.

- 최근 질의 기록의 범위. M10에서 질문 원문은 30일만 보관하기로 했다.
- CSV·이미지 내보내기를 서버와 브라우저 중 어디서 만들지
- 동의어·오타 사전을 누가 관리할지

## 2. 검토한 선택지

| 항목 | 선택지 |
| --- | --- |
| 최근 질의 | 30일 안 최근 20건 / 기간 제한 없이 최근 50건(보관 정책 재결정 필요) |
| 내보내기 | CSV 서버·이미지 브라우저 / 둘 다 브라우저 |
| 동의어 | 코드의 의미 카탈로그 / 관리자 화면 편집 |

## 3. 결정 및 이유

사용자가 모두 권장안을 선택했다. 상세는 [ADR-M15-001](../db/ADR-M15-001.md)에 있다.

- 최근 질의는 30일 안 최신 20건이다. M10 원문 보관 기간과 맞는다.
- CSV는 서버가 권한을 다시 확인해 만들고 감사에 남긴다. 이미지는 브라우저가 화면 차트를 저장한다.
- 동의어는 의미 카탈로그에 코드로 두고 리뷰로 관리한다.
- 실행 계획 재사용 시간, 필터 수정 범위, 후속 질문 문맥, CSV 수식 주입 방지, 표현 변형 일관성(M15-D04~D08)은 SRS와 M10 결정에서 도출한 구현 기준으로 함께 기록했다.

## 4. 구현 내용

- `docs/db/ADR-M15-001.md`: M15-D01~D08을 기록했다.
- 저장소 밖 변경(이 커밋에 포함하지 않음): 작업공간 SRS를 v1.13으로 만들었다. POL-47~49를 추가하고 FR-NL-23·24, FR-AGG-16을 갱신했다.

## 5. 검증 결과

- 문서 변경만 있어 테스트는 실행하지 않았다.
- ADR-M10-001의 원문 보관·결과 상한·권한 결정과 충돌하지 않는지 확인했다.

## 6. 남은 작업 / 보류 사항

- M15는 M10의 실제 엔진 연동(Backend #97)이 끝나야 실제 모델 기준으로 인수할 수 있다.
- M13 고급 필터를 자연어 필터 수정에 연결할지는 M13 계약 확정 뒤 정한다.
