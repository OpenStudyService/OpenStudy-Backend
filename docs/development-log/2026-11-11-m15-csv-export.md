# 2026-11-11 M15 분석 결과 CSV 내보내기 (#127)

## 1. 배경 / 문제

- FR-AGG-16: 정형 집계(M9)와 자연어 분석 결과(M10)를 화면과 같은 수치·조건으로 CSV로 내보낸다.
- #124 계약이 경로·형식·머리말·상한·수식 주입 방지·감사를 정했다. 다만 두 가지는 #127로 미뤘다.
  - 머리말 문장의 정확한 표기
  - 보고서별 열 이름
- 승인 절차는 없다(M15-D09). 이식된 승인 기능은 #214(PR #218)에서 지웠다.

## 2. 검토한 선택지

| 항목 | 선택지 | 결과 |
| --- | --- | --- |
| 수치를 같게 만드는 방법 | 화면 API가 쓰는 서비스를 그대로 호출 / 내보내기용 쿼리 따로 작성 | 같은 서비스 호출. 조건 검증·권한·오류·수치가 화면과 같아진다 |
| 목록형 보고서(원장·상품 순위) | 화면 페이지를 100행씩 이어 읽음 / 서비스에 "전체" 조회 추가 | 이어 읽음. 서비스를 바꾸지 않는다. 최대 11번 호출(1,000행 + 전체 수) |
| 합계 행 | 표 끝에 합계 행 추가 / 넣지 않음 | 넣지 않음. 표를 그대로 계산에 쓸 수 있게 한다. 이용권 판매량은 합계가 결과라 한 행이다 |
| CSV 작성기 | 기존 DomainLens `CsvWriter`(모든 값을 따옴표로 감쌈) / 새 공통 작성기 | 새 `common.export.CsvFile`. 머리말·BOM·상한·필요할 때만 따옴표까지 계약 전체를 한 곳에서 맡는다. 기존 `CsvWriter`는 건드리지 않았다 |

## 3. 결정 및 이유

- **열 이름**: 한국어 이름 뒤 괄호에 단위를 붙인다. 금액은 `(원)`, 건수는 `(건)`, 수량은 `(개)`다. 보고서별 표는 계약 문서에 적었다.
- **AI 결과의 열**: 데이터셋 열 별칭 뒤에 단위를 붙인다. 분석마다 한국어 열 이름 목록을 새로 만들지 않았다.
- **처리 지점(원장)**: ID로 쓴다. 요청자가 볼 수 없는 지점의 이름을 파일에 넣지 않기 위해서다.
- **계약 예시 정정**
  - `잘림,예 (최대 1,000행)`은 값에 쉼표가 있어 따옴표 없이는 칸이 갈라진다. RFC 4180대로 큰따옴표로 감쌌다.
  - "값 없음"을 뜻하는 `-` 하나는 수식이 아니라서 작은따옴표를 붙이지 않는다. 그 밖에 `-`로 시작하는 문자열은 그대로 막는다.
- **감사**: 내보낼 때마다 `EXPORTED` 한 행을 남긴다.
  - `entity_type`은 `ai-execution` 또는 `sales-report`다.
  - `entity_id`는 bigint라 AI 실행 ID(문자열)를 넣을 수 없다. 그래서 비우고, ID는 `after_json`에 넣었다.
  - 감사 검색의 `entityType`은 자유 문자열이라 이 행도 찾을 수 있다.
- **페이지 query**: 내보내기에 `page`·`pageSize`를 보내면 422로 거부한다. 계약의 "페이지 query는 받지 않는다"를 무시하지 않고 명시적으로 알리려는 것이다.
- **빈도 제한**: AI 결과 내보내기는 M10 직원별 빈도 제한에 함께 집계한다. 매출 내보내기에는 빈도 제한이 없다(화면 API와 같다).

## 4. 구현 내용

- 새 `common/export/CsvFile`
  - 머리말 블록, BOM, CRLF, RFC 4180 따옴표, 1,000행 상한과 표시
  - 문자열 수식 주입 방지. 숫자 열의 숫자는 그대로 쓴다.
  - 파일 이름 `<이름>_<YYYYMMDD-HHmm>.csv`(서울 시각), `no-store`
- 새 `SalesExportService`와 `GET /api/sales/exports/{report}`(`SalesController`)
  - 보고서 7종
  - 조건 문장: 기간(서울 날짜, 양 끝 포함), 볼 수 있는 지점 이름, 환불 기준, 용도·상품·분류·단위·고급 필터, 화면의 `conditionNotes`
  - 알 수 없는 보고서는 404 `EXPORT_REPORT_UNKNOWN`
- `AiWorkspaceService.exportExecution`과 `GET /api/ai/executions/{id}/export`
  - #125의 저장 실행 재실행(`rerunSaved`)으로 현재 권한을 다시 확인한다.
  - 조건은 `AiConditions`에서 만든다.
- `ApiException.notFound(code, message)` 추가
- 계약: 두 operation을 `implemented`로 바꿨다. 열 이름 표, 합계 행, 예시 정정을 문서에 적었다.

## 6. 남은 작업 / 보류 사항

- 위 통합 검증 항목(화면 수치 대조, 권한 밖 지점, 상한, 수식 주입, 감사 기록)을 M15 마일스톤 검증에서 실행한다.
