# 2026-11-13 회원 목록 전체 열 정렬

## 배경 및 결정

회원 목록의 모든 열을 제목에서 정렬할 수 있도록 기존 목록 API의 허용 기준을 확장했다. 필터를 적용한 전체 결과를 SQL에서 정렬한 뒤 페이지를 나누므로 페이지를 이동해도 순서가 이어진다.

## 구현

- 이름과 등록일에 더해 회원번호, 연락처, 상태, 등록 지점 이름을 정렬 기준으로 허용한다.
- 상태 오름차순은 정상, 이용 제한, 비활성, 병합됨 순이다. 등록 지점이 없는 회원은 오름차순에서 먼저 표시한다. 정렬 기준 값이 같으면 회원 ID로 순서를 결정한다.
- 정렬 표현식은 허용된 열거형에서 선택하고 등록 지점 정렬에서만 지점 테이블을 연결한다.

## 검증

Docker MySQL을 사용하는 고객 모듈 통합 테스트 14건이 통과했다. 추가한 네 열의 양방향 정렬과 페이지 경계, 지점 미지정 회원을 검증했다. 백엔드 전체 테스트는 실행하지 않았다.
