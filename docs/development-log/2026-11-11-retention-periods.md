# 2026-11-11 정보 종류별 보존 기간 결정 (#99)

## 1. 배경 / 문제

- 자동 파기·정리 규칙(ADR-M11-001 M11-D01)은 보존 기간이 확정될 때까지 비활성이다. #100 구현과 #102 로그 보존 설정이 이 결정을 기다린다.
- #99 인수 조건
  - 정보 종류별 기간과 근거(법령 조항 또는 처리 목적)를 표로 정리한다.
  - 근거를 찾지 못한 항목은 임의 기간을 적지 않고 미정으로 남긴다.

## 2. 검토한 선택지

- 추천안: 고객 1년, 거래 5년, 문의 3년, 근태 3년, 진단 30일, AI 대화 1년, 감사 2년, 백업 30일. 추가로 앱 로그 90일, 재설정·초대 30일, 멱등 만료 후 삭제.
- 사용자 결정(2026-11-11)
  - 추천안을 기준으로 하되, 법령 적용 여부나 기산점이 확인되지 않은 항목은 확정하지 않는다.
  - 일반 감사 이벤트와 법정 접속기록을 구분한다.
  - 퇴사 직원 계정은 별도 정책으로 둔다.
  - #100은 확정 항목만 구현하고, #99는 미결정이 해소될 때까지 닫지 않는다.

## 3. 결정 및 이유

- 법령 확인(2차 자료: 해설·위키·언론. 원문 대조는 미결정으로 남김)
  - 국세기본법 제85조의3: 장부·증거서류 5년, 기산점은 **과세기간의 법정신고기한이 지난 날**이다. 상법 상업장부 10년을 함께 드는 자료가 있어 해당 여부 확인이 필요하다.
  - 전자상거래법 시행령 제6조: 계약·대금결제 5년, 소비자 불만·분쟁처리 3년. 이 서비스가 적용 대상인지 확인되지 않았다.
  - 근로기준법 제42조·시행령 제22조
    - 근로자 명부·근로계약서·임금대장 등은 3년이다.
    - 기산점은 서류마다 다르다: 퇴직일, 근로관계 종료일, 마지막 기재일.
    - 출퇴근 기록이 보존 대상인지는 해석이 갈린다.
  - 개인정보의 안전성 확보조치 기준
    - 제8조: 접속기록 1년 이상. 정보주체 5만 명 이상이거나 고유식별·민감정보를 처리하면 2년 이상이다.
    - **제5조 제3항: 권한 부여·변경·말소 기록 최소 3년**(새로 확인한 항목이다)
  - 개인정보 보호법 제39조의6(유효기간제)은 2023-09-15 시행 개정으로 삭제되었다.
- 결과(ADR-M11-002)
  - 확정
    - 고객 식별 정보: 마지막 이용 후 1년, 익명화
    - AI 대화: 마지막 질문 후 1년
    - 진단 로그 원문: 30일
    - 백업: 30일
    - 앱 로그: 90일
    - 재설정·초대 처리 이력: 30일
    - 멱등 기록: 만료 후 삭제
    - 접속기록 최소 1년, 권한 이력 최소 3년
  - 미결정: 거래 기록, 문의, 근태, 접속기록 2년 요건, 일반 감사 이벤트, 퇴사 직원 계정
  - 추천안의 "감사 2년"은 법정 접속기록·권한 이력·일반 감사로 나눴다. 일반 감사는 법정 기간이 없고 보유 목적도 정하지 않아 미결정이다.
