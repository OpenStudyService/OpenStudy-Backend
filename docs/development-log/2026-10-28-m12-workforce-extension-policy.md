# 2026-10-28 M12 근태 정정 방식·휴가 처리 지점·휴가와 근무 충돌·대체근무 동의 정책 확정

## 1. 배경 / 문제

M12(인력 운영 확장) 이슈를 작성하려고 SRS v1.9의 M12 요구사항 14개와 V1 스키마를 대조했다. 테이블은 대부분 있지만 다음이 맞지 않거나 정해지지 않았다.

- SRS는 근태 정정을 "정정 출퇴근 시각 + 총 휴게 분"으로 받지만, V1 `attendance_corrections`는 출퇴근 시각과 휴게 구간을 따로 정정하는 구조다.
- SRS는 휴가 신청에 지점을 받지만, V1 `leave_requests`에는 지점이 없다. 휴가를 처리할 관리자가 정해지지 않았다.
- 승인할 휴가 기간에 예정 근무가 있을 때의 처리가 정해지지 않았다.
- 대체근무에 대체 직원의 동의가 필요한지 정해지지 않았다.

## 2. 검토한 선택지

| 항목 | 선택지 |
| --- | --- |
| 정정 방식 | V1 구간 방식 유지 / SRS 총 휴게 분 방식(마이그레이션 필요) |
| 휴가 처리 | 소속 지점 중 한 곳의 MANAGER 이상 / OWNER만 / 신청에 지점을 두고 그 지점 MANAGER(마이그레이션 필요) |
| 휴가·근무 충돌 | 승인 거부 / 승인하면서 근무 자동 취소 |
| 대체 동의 | 동의 단계 없음 / 대체 직원 동의 후 승인(마이그레이션 필요) |

## 3. 결정 및 이유

사용자가 결정했다. 상세는 [ADR-M12-001](../db/ADR-M12-001.md)에 있다.

- 정정은 V1 구간 방식을 유지한다. 실근무 계산 기준이 하나로 유지된다.
- 휴가 신청에 지점을 두고 그 지점 MANAGER 이상이 처리한다. 사용자가 권장안(소속 지점 중 한 곳) 대신 SRS 문구에 맞는 방식을 골랐고, 이를 위해 마이그레이션 하나가 필요하다.
- 휴가 기간에 예정 근무가 있으면 승인을 거부한다.
- 대체근무에 동의 단계를 두지 않는다.
- 정정·대체 처리 권한, 휴가 일수와 차감 순서, 중복 반영 방지, 정정 승인 검증, 대체 승인 취소 조건(M12-D05~D09)은 SRS와 V1에서 도출한 구현 기준으로 함께 기록했다.

## 4. 구현 내용

- `docs/db/ADR-M12-001.md`: M12-D01~D09와 스키마 영향을 기록했다.
- 저장소 밖 변경(이 커밋에 포함하지 않음): 작업공간 SRS를 v1.10으로 만들었다. POL-35~38을 추가하고 FR-CORR-01, FR-LEAVE-01·02·03, FR-SWAP-01을 갱신했다.

## 5. 검증 결과

- 문서 변경만 있어 테스트는 실행하지 않았다.
- V1 DDL(`attendance_corrections`, `leave_requests`, `leave_grants`, `leave_allocations`, `leave_balance_events`, `shift_swaps`)을 읽어 결정과 맞는지 확인했다.

## 6. 남은 작업 / 보류 사항

- 자동 법정 휴가 계산은 범위 밖이다. 휴가는 수동 부여만 한다.
- M8의 승인 휴가 충돌 검사(M8-D06)를 M12의 실제 승인 데이터로 다시 검증한다.
