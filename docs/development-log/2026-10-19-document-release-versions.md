# 정책 변경 문서 버전 동기화

Docker 테스트 DB 정책의 공통 요구사항·WBS를 v1.2로 릴리스하고 개정 이력에 수정 내용·범위·검증·남은 작업을 기록했다. 이전 v1.1 문서는 변경 전 상태로 보존했다. API 추적·설계 문서의 최신 문서 참조도 v1.2로 갱신했다.

정책 변경을 반영한 개발 실행 계획은 `docs/OpenStudy_에이전트_개발_실행계획_v1.1.md`로 분리하고 자체 개정 이력을 추가했다. 기존 v1.0 실행 계획은 이전 Git 배포 내용으로 보존했다. 기준 요구사항/WBS 버전과 실행 계획 자체 버전은 구분한다.

공통 문서의 기존 수식·일정·공수·진행 상태와 이전 버전 보존을 검증했다. 이번 수정은 문서 릴리스 관리이며 코드·의존성·테스트 연동을 추가 구현하지 않았다. 커밋·push는 수행하지 않았다.
