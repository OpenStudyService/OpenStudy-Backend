# ADR-M11-002 · 정보 종류별 보존 기간

- 상태: **일부 확정(사용자 의사결정)**. 법령 적용 여부·기산점이 확인되지 않은 항목은 **미결정**으로 남긴다.
- 기록일: 2026-11-11
- 적용 범위: M11 릴리스 검증·운영 준비. #99(결정), #100(구현)
- 근거: `FR-MEM-09`, `FR-AUD-05`, `NFR-SEC-09`, `NFR-PERF-08`, POL-02·POL-03·POL-31·POL-51, ADR-M11-001 M11-D01·D05, ADR-M10-001 M10-D04, ADR-M10-002 M10-D13
- 이 문서는 정책 결정 기록이다. 법률 자문이 아니다. 법령 조항은 2026-11-11 기준 2차 자료(해설·위키·언론)로 확인했다. 국가법령정보센터 원문 대조는 "미결정 사항"에 남긴다.

## 원칙

- 개인정보는 보유 기간이 지나거나 처리 목적을 달성하면 지체 없이 파기한다. 다른 법령이 보존을 요구하면 분리해 보관한다(개인정보 보호법 제21조).
- 옛 "1년 미이용 파기"(제39조의6, 유효기간제)는 2023-09-15 시행 개정으로 삭제되었다. 그래서 고객 정보 기간은 처리 목적을 기준으로 정한다.
- **법령 적용 여부나 기산점이 확인되지 않은 항목은 확정하지 않는다.** 그 항목의 자동 파기·정리 규칙은 ADR-M11-001 M11-D01대로 비활성으로 둔다.
- #100은 이 문서의 **확정** 항목만 활성 규칙으로 구현한다.
