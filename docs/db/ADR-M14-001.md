# ADR-M14-001 · 비밀번호 초기화 전달, 세션 처리, 프로필 사진 저장소, 감사 로그 조회 범위

- 상태: **확정(사용자 의사결정)** · M14-D05~D10은 SRS 문구와 V1 스키마·현재 코드에서 도출한 구현 기준이며 리뷰에서 조정할 수 있다.
- 기록일: 2026-10-29
- 적용 범위: M14 계정·협업·설정 확장
- 관련: `docs/design-decisions/decision-register.md` M1-06·M1-07(세션 유효시간·권한 변경 후 세션), [ADR-M7-001](ADR-M7-001.md)(채널 참여 자격 M7-D07)
- 근거: `FR-AUTH-13/14`, `FR-SET-02/03`, `FR-CHAT-03/08`, `FR-AUD-04`, SRS v1.12 POL-43~46

## 결정

| ID | 최종 결정 | 선택 이유/결과 |
| --- | --- | --- |
| M14-D01 | **관리자 비밀번호 초기화는 직원 이메일로 한 번만 쓸 수 있는 만료 있는 재설정 링크를 보낸다.** 직원이 링크에서 새 비밀번호를 정한다. 관리자는 비밀번호를 볼 수 없고, 토큰·비밀번호 원문은 응답·로그에 남지 않는다. 기존 초대 메일 발송 구조를 재사용한다. | FR-AUTH-14의 안전한 전달과 최초 사용 시 변경을 한 번에 충족한다. |
| M14-D02 | **본인이 비밀번호를 바꾸면 현재 세션만 남기고 다른 세션을 모두 종료한다. 관리자가 초기화하면 그 직원의 모든 세션과 SSE 연결을 종료한다.** | 비밀번호 유출 대응 시 다른 기기의 접근을 바로 끊는다(M1-07과 같은 방향). |
| M14-D03 | **프로필 사진은 S3 비공개 버킷에 저장한다.** 앱이 검증한 뒤 올리고, 조회는 앱을 거치거나 짧은 만료의 서명 URL로 한다. 버킷·IAM 권한은 인프라 팀원에게 요청한다. | 컨테이너 재시작과 다중 인스턴스에서도 유지되고 DB 백업 크기를 늘리지 않는다. |
| M14-D04 | **감사 로그 검색·변경 상세는 OWNER만 조회한다.** | 사용자 선택. 감사 정보는 전사 보안 정보로 본다. |
| M14-D05 | **비밀번호 초기화는 대상 직원이 소속된 지점에서 `people:manage`가 있는 관리자가 요청한다. OWNER 계정의 초기화는 다른 OWNER만 할 수 있다.** 재설정 토큰은 해시만 저장하고 1시간 뒤 만료되며 한 번 쓰면 무효가 된다. 새 토큰을 만들면 이전 토큰은 무효가 된다. | 지점 권한을 넘어 다른 직원 계정을 다루지 못하게 한다. 토큰 저장 테이블은 다음 미사용 번호의 마이그레이션으로 추가한다. |
| M14-D06 | **"계정 잠금"은 로그인 반복 실패로 걸린 계정 단위 제한(`LoginAttemptLimiter`)을 뜻한다.** 잠금 해제는 그 계정의 제한 기록을 지운다. 계정 상태(`SUSPENDED` 등)의 변경은 기존 직원 관리 기능이 맡는다. 제한기는 인스턴스 메모리라 다중 인스턴스에서는 모든 인스턴스에 반영되지 않는 한계를 기록한다. | V1에 별도 잠금 칼럼이 없고 현재 잠금 동작은 제한기뿐이다. |
| M14-D07 | **1:1 대화 상대는 요청자와 활성 소속 지점을 하나 이상 공유하는 활성 직원이다.** 같은 두 사람의 대화방은 V1 `conversations`의 DM 유니크 키로 재사용한다. 소속 공유가 끊기거나 계정이 비활성화되면 새 메시지 전송을 막는다. | FR-CHAT-03의 "허용된 동료"를 지점 소속으로 정의한다. |
| M14-D08 | **채팅 실시간은 기존 공통 워크스페이스 SSE와 분리된 채팅 전용 스트림으로 제공한다.** 이벤트마다 수신자의 현재 참여 권한을 확인하고, 연결·재연결 시 클라이언트는 채널·메시지·업무를 다시 조회한다. 로그아웃·권한 회수·계정 비활성 시 스트림을 닫는다. 단일 인스턴스 기준으로 만들고, 다중 인스턴스 전달은 기존 SSE와 같은 후속 과제로 둔다. | 마일스톤 비고의 "채팅 전용 실시간과 현재 공통 SSE를 구분한다". |
| M14-D09 | **화면 테마는 브라우저 저장소에만 둔다.** 서버에 저장하지 않는다. | FR-SET-03이 "같은 브라우저 재방문 유지"만 요구한다. |
| M14-D10 | **프로필 사진은 서버에서 파일 시그니처로 JPG·PNG·WebP를 판별하고 5MB를 넘으면 거부한다.** 확장자나 Content-Type만 믿지 않는다. | FR-SET-02의 서버 검증. |

## 스키마 영향

비밀번호 재설정 토큰 테이블을 다음 미사용 번호의 마이그레이션으로 추가한다. V1은 수정하지 않는다. 프로필 사진은 기존 `employees.avatar_url`에 저장소 키를 둔다.
