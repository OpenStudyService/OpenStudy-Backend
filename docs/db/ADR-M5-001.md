# ADR-M5-001 · 이용권 사용 지점, 타 지점 입실 조회, 좌석 이용 차감

- 상태: **확정(사용자 의사결정)**
- 기록일: 2026-10-28
- 적용 범위: M5 좌석 이용·이용권 차감
- 관련: [ADR-M4-002](ADR-M4-002.md)(고객 조회 범위 M4-D05, 환불 권한 M4-D08). 이 ADR은 M4-D05를 바꾸지 않는다.
- 근거: `FR-PASS-12/13`, `FR-SEAT-06/07/14/17/18`, `FR-MEM-07`, `NFR-SEC-06`, SRS v1.3 POL-07~10

## 결정

| ID | 최종 결정 | 선택 이유/결과 |
| --- | --- | --- |
| M5-D01 | **이용권은 판매 지점과 관계없이 모든 활성 지점에서 사용할 수 있다.** | 고객이 지점을 옮겨 다녀도 같은 이용권으로 이용할 수 있게 한다. 기존 문서에서 "정책 보류"였던 FR-PASS-13을 확정한다. 상품 판매 지점은 판매 범위로만 쓴다. |
| M5-D02 | **정액권 차감액 = `ceil(이용 분 × 구매 당시 시간당 요율 ÷ 60)`원.** 이용 분은 분 단위 올림이다. | 분 올림과 같은 방향으로 정수 원화가 되도록 한다(NFR-DATA-05). |
| M5-D03 | **기간권 이용 중 만료되면 퇴실은 정상 처리하고, 만료 시각 이후 이용 분을 `overage_minutes`로 기록한다.** 자동 퇴실은 하지 않는다. | 스케줄러 없이 이용 기록을 끊지 않으면서 만료 후 이용을 드러낸다. |
| M5-D04 | **잔여량·유효기간 수동 조정은 구매 지점의 `payments:write` 보유자가 한다.** | 환불(M4-D08)과 같은 권한 기준을 쓴다. |

| M5-D07 | **정확 일치 조회 결과는 `customer_service_interactions`에 기록한다.** 일치한 고객마다 조회 직원·조회 지점·시각을 남긴다. 일치하는 고객이 없는 조회는 이 테이블에 남길 수 없으므로(`customer_id` 필수) 공통 `audit_events`에 결과와 함께 남긴다. | 기존에 "응대 중인 고객의 전 지점 조회 근거와 접근 감사" 용도로 만든 테이블을 그대로 쓴다. |
| M5-D08 | **정확 일치 조회의 횟수 제한은 M5에 포함하지 않고 후속 과제로 분리한다.** 제한값도 정하지 않는다. | 아래 "Rate Limiter 재사용 검토" 참고. |

## Rate Limiter 재사용 검토

기존 `LoginAttemptLimiter`(`modules/auth/service`)를 검토했다.

- 고정 창 계수기와 용량 초과 시 정리 로직은 일반적이지만, 클래스 내부(`private static final class Window`)에 묶여 있다.
- 공개 API는 `check(email, source)`·`success(email)`로 로그인 전용이다. 이메일 정규화, 계정·출처 두 범위, `LoginRateLimitedException`이 고정되어 있다.
- 429 응답 변환은 `AuthController`의 로그인 처리 안에서만 한다. 공통 예외 처리에 연결되어 있지 않다.
- 상태는 인스턴스 메모리에만 있어 재기동 시 초기화되고, 다중 인스턴스에서는 공유 저장소가 필요하다.

조회 제한에 쓰려면 계수기를 공통 컴포넌트로 분리하고, 새 키(직원·지점) 기반 제한 서비스와 공통 429 응답을 만들고, 보안 시험이 있는 로그인 제한을 같이 고쳐야 한다. 단순 확장이 아니므로 M5에서 제외했다. 정상 입실 업무에 지장을 주지 않는 제한값은 실제 사용량을 근거로 정해야 하므로 임의로 확정하지 않는다.

M5에서는 정확 일치 조회를 한 서비스 진입점으로만 처리해, 후속 제한을 그 지점에 붙일 수 있게 한다.

## 영향

- M5 입실 API는 고객 ID 대신 정확 일치 조회 결과의 고객·이용권을 사용할 수 있다.
- M5 퇴실·이동 API는 이용 기록 ID와 그 지점 권한으로 처리한다.
- 고객 상세·구매·사용 내역(FR-MEM-07)은 M4-D05 범위를 그대로 따른다. 다른 지점 고객의 내역은 볼 수 없다. 타 지점 이력 요약(POL-01)은 M6 범위다.
- 입퇴실 이력(FR-SEAT-18)은 조회 지점의 이용 기록을 보여 주며, 고객 정보는 최소 정보로 표시한다.
