# ADR-M10-003 · 자연어 분석을 등록 분석 방식으로 확정

- 상태: **확정(사용자 의사결정)** · M10-D14~D17은 2026-11-08 사용자 선택이다.
- 기록일: 2026-11-08
- 적용 범위: M10 자연어 분석(AI 채팅). Backend #93~#97의 인수 조건 해석을 바꾼다.
- 관련: [ADR-M10-001](ADR-M10-001.md)(엔진 경계·포트), [ADR-M10-002](ADR-M10-002.md)(AI 채팅·대화 저장), [ADR-M9-001](ADR-M9-001.md)(공통 집계), 계약 [nl-analysis-api.md](../design/foundation/nl-analysis-api.md)

## 배경

#93~#96의 인수 조건은 범용 흐름을 전제로 썼다. 모델이 IR을 만들고, 서버가 IR을 검증해 QuerySpec으로 바꾼 뒤 JPA로 실행하는 흐름이다.

2026-11-08 main 코드를 대조한 결과는 다음과 같았다.

- 실제 AI는 **등록된 분석 10개(POC-001~010) 중 하나를 고르는 방식**이다.
  - 모델(또는 고정 생성기)은 분석 ID만 고르고, 고를 수 있는 값은 JSON 스키마 enum으로 제한된다.
  - 서버는 그 분석에 미리 정한 집계(M9 서비스 호출 포함)를 실행한다.
- DomainLens 범용 엔진 코드(`QueryPipeline`, `IrValidator`, `JpaQueryExecutor`)는 저장소에 있지만 연결돼 있지 않다.
- 이식 코드에 데모 데이터 하드코딩이 있었다.
  - 데모 지점 ID 9100001~3과 이름 "강남·성수·신규점"
  - 특정 직원 ID(9200003)의 매출 권한 예외
  - 고정 기준 시각 2026-11-02 14:00(운영 기본값)

### 함께 정한 구현 기준

- 질문 속 지점은 실제 지점 이름(전체 이름, 또는 "점"으로 끝나면 그 앞부분)으로 찾는다.
- 권한이 없는 지점을 질문하면 그 지점의 이름·수치를 응답에 담지 않는다(#94).
- OWNER의 "전체"는 OWNER가 읽을 수 있는 모든 지점이다(M9-D04 합집합).
- 직원이 "전 지점"을 물으면, 모든 지점의 `ai:read`가 있을 때만 허용한다.
- 직원·지점 ID에 따른 예외 규칙은 두지 않는다.
- 품질 평가(`/api/ai/evaluation/run`)는 OWNER만 실행하고, OWNER가 읽을 수 있는 실제 지점으로 실행한다.

## #93~#96 인수 조건의 해석

- IR 구조·버전 검증(#94)은 "모델 출력이 등록 분석 ID·부가 조건 enum을 벗어나면 실행하지 않는다"로 읽는다.
- QuerySpec 실행(#95)은 "등록 분석의 고정 집계를 실행한다"로 읽는다. M9 정형 API와의 수치 동등성은 등록 분석마다 확인한다.
- 상대 기간("지난 7일", "이번 달")은 분석마다 정해진 기간을 쓴다. 질문에서 임의 기간을 읽지 않는다.
- SSE 관련 항목은 [ADR-COM-001](ADR-COM-001.md)로 대체됐다.

## 남은 일

- 실제 준비 상태(#93), 질문 원문 30일 삭제(#96, M10-D04), 중복 제출 방지(#96)는 다음 작업에서 구현한다.
- 범용 엔진 연결 여부는 #97에서 정한다.

## 후속 변경 (2026-11-13)

위 "#93~#96 인수 조건의 해석" 중 "상대 기간은 분석마다 정해진 기간을 쓴다. 질문에서 임의 기간을 읽지 않는다"는 2026-11-13 사용자 요청으로 바꿨다. 기존 본문은 당시 결정으로 보존한다.

- 등록 분석도 질문이 지정한 기간("지난 달", "지난주", "최근 30일", "2026년 10월", "2026년 9월부터 10월까지")을 서버 시계(KST)로 읽어 실행한다. 기간 표현이 없거나 분석 기본 기간과 같은 뜻이면 기본 기간을 쓴다.
- 기간이 둘 이상이면 확인 질문(`PERIOD_AMBIGUOUS`)을, 분석별 최대 기간(조건 변경과 같은 상한)을 넘으면 확인 질문(`PERIOD_TOO_LONG`)을 돌려준다.
- 이유: "이번 달 지점별 매출"과 "지난 달 지점별 매출"이 같은 결과를 내, 사용자가 다른 기간의 수치를 자기 질문의 답으로 오해할 수 있었다.
