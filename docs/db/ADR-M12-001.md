# ADR-M12-001 · 근태 정정 방식, 휴가 처리 지점, 휴가와 근무 충돌, 대체근무 동의

- 상태: **확정(사용자 의사결정)** · M12-D05~D09는 SRS 문구와 V1 스키마에서 도출한 구현 기준이며 리뷰에서 조정할 수 있다.
- 기록일: 2026-10-28
- 적용 범위: M12 인력 운영 확장
- 관련: [ADR-M8-001](ADR-M8-001.md)(근무표 권한 M8-D01, 승인 휴가 충돌 M8-D06, 실근무 분 M8-D07)
- 근거: `FR-CORR-01~04`, `FR-LEAVE-01~06`, `FR-SWAP-01~04`, SRS v1.10 POL-35~38

## 결정

| ID | 최종 결정 | 선택 이유/결과 |
| --- | --- | --- |
| M12-D01 | **근태 정정은 V1 구조대로 출퇴근 시각 정정과 휴게 구간별 정정을 각각 신청한다.** 승인되면 해당 구간을 바꾸고 실근무 분은 M8-D07 계산을 그대로 쓴다. "총 휴게 분" 입력은 쓰지 않는다. | 스키마 변경 없이 근태 계산 기준을 하나로 유지한다. SRS FR-CORR-01 문구를 이에 맞게 고친다. |
| M12-D02 | **휴가 신청에 지점을 둔다. 그 지점의 MANAGER 이상이 신청을 승인·반려·승인 취소한다.** 신청 지점은 신청자의 활성 소속 지점이어야 한다. 휴가 부여는 원부여 지점(`leave_grants.origin_branch_id`)의 MANAGER 이상이 한다. 잔여량은 지점과 무관하게 직원 단위로 합산한다. | SRS FR-LEAVE-02의 "지점" 입력을 따른다. V1 `leave_requests`에는 지점 칼럼이 없으므로 다음 미사용 번호의 마이그레이션으로 추가한다. |
| M12-D03 | **승인하려는 휴가 기간에 취소되지 않은 예정 근무가 있으면 승인을 거부하고 겹치는 근무를 알려 준다.** 관리자가 근무를 취소하거나 대체근무를 처리한 뒤 승인한다. | M8의 근무 충돌 검사와 같은 방향이다. 승인과 근무 변경이 한 번에 섞이지 않는다. |
| M12-D04 | **대체근무는 원래 담당자가 본인 근무에 대해서만 신청하고, 관리자 승인만 거친다. 대체 직원의 동의 단계는 없다.** | SRS에 동의 단계가 없다. 현장 협의는 승인 전에 관리자가 확인한다. 스키마 변경이 없다. |
| M12-D05 | **근태 정정과 대체근무의 승인·반려·승인 취소는 근태·근무가 기록된 지점의 MANAGER 이상이 한다.** 신청·신청 취소는 본인만 한다. | M8-D01·D02와 같은 지점 기준이다. |
| M12-D06 | **휴가 신청 일수는 0.5일 단위이고 신청 기간의 달력 일수를 넘을 수 없다. 연도를 넘는 신청은 받지 않는다(V1 제약).** 승인 시 신청 기간을 포함하는 유효한 부여에서 만료일이 빠른 순으로 차감하고, 배분을 `leave_allocations`에 남긴다. | 잔여량을 부여별로 추적하고 취소 시 같은 부여로 복원할 수 있게 한다. |
| M12-D07 | **사용·복원은 요청당 한 번만 반영한다.** 상태 전이는 버전으로 막고, 잔여량 원장(`leave_balance_events.event_key`)에 요청 ID와 사건 종류로 만든 고유 키를 써서 중복 반영을 DB에서 막는다. | FR-LEAVE-03·05와 M12 완료 기준 4의 "동시·반복 요청 중복 변경 금지". |
| M12-D08 | **정정 승인 시 정정된 구간이 같은 직원의 다른 근태와 겹치거나, 휴게가 근무 구간 밖이면 거부한다.** 원본 값은 정정 기록(`before_*`)에 남는다. 승인된 정정은 취소하지 않고 새 정정 요청으로 바꾼다. | FR-CORR-02·04. 원본·정정·승인자를 보존한다. |
| M12-D09 | **대체근무 승인 취소는 승인 이후 근무가 바뀌지 않았고(버전 동일), 원래 담당자의 같은 시간대에 새 충돌이 없을 때만 원래 담당·시간으로 복원한다.** 승인과 복원은 근무 변경 이력(`shift_events`, `SWAPPED`)으로 남긴다. | FR-SWAP-04. |

## 스키마 영향

`leave_requests`에 신청 지점 칼럼을 추가하는 마이그레이션 하나가 필요하다(M12-D02). 다음 미사용 번호를 쓰고 V1은 수정하지 않는다. 나머지는 V1의 `attendance_corrections`, `leave_grants`, `leave_allocations`, `leave_balance_events`, `shift_swaps`, `shift_events`로 구현한다.
