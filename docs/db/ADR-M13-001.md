# ADR-M13-001 · 지점 휴무 효과, 판매 한도, 고객 병합, 마감 후 변경

- 상태: **확정(사용자 의사결정)** · M13-D05~D10은 SRS 문구와 V1 스키마에서 도출한 구현 기준이며 리뷰에서 조정할 수 있다.
- 기록일: 2026-10-28
- 적용 범위: M13 운영·거래 확장
- 관련: [ADR-M9-001](ADR-M9-001.md)(공통 집계 기반·환불 기준), [ADR-M4-002](ADR-M4-002.md)(고객 조회 범위·환불), [ADR-M6-001](ADR-M6-001.md)(룸 예약)
- 근거: `FR-BR-09`, `FR-PROD-10`, `FR-MEM-08`, `FR-SEAT-16`, `FR-PAY-13/14`, `FR-AGG-15`, SRS v1.11 POL-39~42

## 결정

| ID | 최종 결정 | 선택 이유/결과 |
| --- | --- | --- |
| M13-D01 | **지점 휴무일은 화면·홈에 안내하고, 그날 시작하는 스터디룸 신규 예약만 막는다.** 이미 있는 예약은 자동 취소하지 않고 휴무일 등록 시 경고로 알린다. 판매·입실·출근·근무 등록은 막지 않는다. | 휴무일에도 정리 업무가 있을 수 있다. 미래 시간대를 파는 룸 예약만 휴무와 직접 충돌한다. |
| M13-D02 | **판매 한도는 상품 하나에 모든 지점을 합친 수량이다. 승인된 판매만 세고, 환불하면 다시 판매할 수 있다.** 동시 판매에서도 한도를 넘지 않는다. 판매 기간이 지나거나 한도를 넘으면 신규 판매를 거부한다. | 상품 단위 운영이 단순하고, 환불된 수량을 다시 팔 수 있게 한다. |
| M13-D03 | **고객 병합은 OWNER만 하고 되돌리지 않는다.** 흡수된 고객은 삭제하지 않고 '병합됨' 상태와 병합 대상 고객 참조를 남긴다. 병합 이력(대상, 흡수 고객, 처리자, 시각, 사유)을 보존한다. | 여러 지점의 거래를 합치므로 최상위 역할로 제한한다. 병합 취소 규칙은 복잡도에 비해 필요성이 낮다. |
| M13-D04 | **일별 마감 후에도 환불 같은 변경은 허용한다. 마감된 날에 영향을 주는 변경은 사유와 함께 마감 조정 이력으로 남기고, 마감 금액과 현재 금액의 차이를 보여 준다.** 마감은 지점 MANAGER 이상이 한다. | 마감 때문에 고객 환불이 막히지 않게 하면서 변경을 추적한다. |
| M13-D05 | **휴무일은 지점별 날짜(Asia/Seoul 하루 전체)로 관리하고, 등록·수정·삭제는 해당 지점 MANAGER 이상이 한다.** | FR-BR-09의 관리 권한 검증. |
| M13-D06 | **판매 기간(시작·종료 시각)과 한도는 선택 값이다.** 비어 있으면 제한하지 않는다. 판매 가능 여부는 판매 상태 → 판매 기간 → 남은 한도 순서로 확인한다. | 기존 상품이 설정 없이 그대로 동작한다. |
| M13-D07 | **병합 시 기존 결제·이용권·이용 기록의 고객 참조는 바꾸지 않는다.** 대상 고객의 상세·이력·집계는 흡수된 고객의 기록을 함께 보여 준다. 병합 전 두 고객 모두 OWNER가 볼 수 있어야 한다. | FR-MEM-08의 "기존 참조 보존". 원거래를 고치지 않아 감사 추적이 쉽다. |
| M13-D08 | **마감은 지점·날짜(Asia/Seoul) 단위로, M9 공통 집계의 그날 승인액·환불액·순매출을 스냅샷으로 남긴다.** 같은 지점·날짜는 한 번만 마감한다. | FR-PAY-14. 마감 기준을 정형 집계와 같게 둔다. |
| M13-D09 | **좌석 점유 추이는 시간·일 단위 구간별로 `점유한 좌석·분 ÷ (좌석 수 × 구간 분)`을 계산한다.** 각 구간 값은 `seat_sessions`로 다시 계산할 수 있다. | FR-SEAT-16. 동시 점유의 평균을 원천 기록으로 재현한다. |
| M13-D10 | **결제 고급 필터(결제 수단·상품 분류·처리자)와 고급 집계 필터(상품 유형·판매 지점·이용 지점·환불 기준)는 M9 공통 집계 조건을 확장해 목록과 집계에 같이 적용한다.** 현재 환불은 전액 환불 한 종류뿐이므로 "환불 유형"은 환불 기준(처리일·원결제일)과 처리 지점으로 구분한다. | FR-PAY-13, FR-AGG-15. 목록과 집계의 합계가 일치한다. |

## 스키마 영향

다음을 다음 미사용 번호의 마이그레이션으로 추가한다. V1은 수정하지 않는다.

- 지점 휴무일 테이블
- `products`의 판매 시작·종료 시각과 판매 한도 칼럼
- `customers`의 병합 대상 참조와 '병합됨' 상태, 병합 이력 테이블
- 일별 마감 테이블과 마감 조정 이력 테이블
