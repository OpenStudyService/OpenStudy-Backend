# GitHub 등록 준비 파일

아직 원격 마일스톤·이슈를 등록하지 않았다. 이 파일들은 실행 예약이나 자동 배정이 아니다.

논리 마일스톤은 3개이며 GitHub milestone은 저장소별 자원이므로 frontend/backend 각 저장소에 같은 3개를 만든다(원격 자원 6개). 담당자와 기한은 지정하지 않았다. 기존 동명 항목을 먼저 확인하고 중복 등록하지 않는다.

[registration.json](registration.json)에 대상 저장소·선행 관계·마일스톤·본문 파일이 있다. 등록 전 패키지 PR/기준 커밋과 실제 선행 링크를 연결한다. B02는 이번 전달 브랜치에서 완료했으므로 재개발하지 않는다.
